# SQL Quest by Eternity Squared Tech

A browser game for learning SQL. Students play the new business analyst at Brightside Electronics, a small gadget shop, and answer questions from the managers by writing real SQL queries.

Play it here: https://eternitysquaredtechnologies.github.io/sql-quest/

## What's inside

- 51 missions across 10 levels
- Beginner (levels 1 to 6): SELECT, WHERE, ORDER BY, GROUP BY, HAVING and JOINs
- Intermediate (levels 7 to 10): subqueries, CASE, COALESCE, dates, WITH and window functions
- Answers are checked by comparing results, so any correct query passes
- Stars, hints and ranks. Progress is saved in the browser.

The database runs in the browser using [sql.js](https://github.com/sql-js/sql.js), so there is nothing to install. `brightside.sql` rebuilds the same database in any SQLite tool.
